专为极客打造的 CLI

通过一行命令即可安装 CLI 版本，完美融入您的自动化工作流脚本中。

终端 (Terminal)
sudo curl -L "https://github.com/cduyzh/LivePhotoForge/releases/latest/download/LivePhotoForge" -o /usr/local/bin/livephoto && sudo chmod +x /usr/local/bin/livephoto

常见用法

  • livephoto video.mp4 - 自动转换并直接导入相册
  • livephoto --frame-time 2.5 video.mp4 - 截取视频第 2.5 秒作为封面
  • livephoto -o ~/Desktop/LivePhotos/ video.mp4 - 仅输出到指定目录，不导入图库
